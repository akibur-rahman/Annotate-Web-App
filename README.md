## Description
Annotating image data is an essential task for supervised ML operations. Most of the annotation tools are either paid or aren't good enough. That's why I have decided to build my own. This tool can annotate image data with ease and save the annotations along with images.


## Installation

To run this project need to install  Xampp

Xampp: https://www.apachefriends.org/download.html


    
## Run Locally

Clone the project

```bash
  git clone https://github.com/akibur-rahman/Annotate-Web-App.git
```
```bash
1.Go to the project directory
2.Copy all the files to your xampp\htdocs\annotate
3.Open Xampp and turn on apache and MySQL
4.Go to PhpMyAdmin and import the annotate.sql 
5.Then go to http://localhost/annotate/
```
